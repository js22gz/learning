Finding

  1. Prestation skilde sig inte konsekvent mellan longhand, laptop, eWriter — eller ingen anteckning.
  2. Skillnader minskade efter studium av anteckningar.
  3. Meta av direkta replikationer: små, icke-signifikanta longhand-effekter.
  4. För tidigt att utropa en överlägsen metod för anteckningens funktioner.

Mechanism

Direkt replikation nyanserar encoding-fördelen penna>tangentbord; mekanismen (verbatim vs generativ anteckning) är uppgifts- och populationsberoende.

Limits

HE-labb; kortsiktiga quiz — inte hela kursbetyg (jfr HAND-003).

This claim dies if …

Preregistrerad replikering där tangentbord ≥ penna på conceptual/closed-book-utfall i samma population när anteckningsinstruktion hålls konstant.

Swedish implication

Start penna när conceptual encoding är målet; measure retention, inte bara anteckningsvolym.
