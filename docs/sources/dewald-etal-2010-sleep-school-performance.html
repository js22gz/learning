Finding

Tre meta-analyser: 1. Sleepiness ↔ skolprestation: r ≈ −0,13 (starkast) 2. Sömnkvalitet ↔ prestation: r ≈ 0,10 3. Sömnlängd ↔ prestation: r ≈ 0,07 4. Större effektstorlekar hos yngre deltagare (prefrontal mognad).

Mechanism

Skärmtid nära sänggåendet förskjuter sömn och minskar sömnkvalitet, vilket försämrar konsolidering av lärande.

Limits

  • Korrelation ≠ kausalitet; små r; mätheterogenitet.
  • Kompletteras av experiment (SLEEP-007).

This claim dies if …

Longitudinell/RCT-evidens där ökad kvällsskärm inte försämrar sömn eller nästa-dag-retention efter confound-kontroll.

Swedish implication

Stop skärm i sovrum/kvällsrutin före sänggåendet; measure sömn + skoldagsform.
