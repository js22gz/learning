Finding

  1. Efter GenAI-adoption: läxpoäng +18 %, tid per läxa −30 %.
  2. Månatliga closed-book-prov: −20 % inom sex månader.
  3. High-stakes entrance exams: −18 till −24 %; full penalty syns först efter ~två år.
  4. Störst förlust: samhällsorienterade ämnen > STEM > språk; junior pupils, high-achievers, pojkar.
  5. ~80 % av AI-användare beter sig som homework outsourcing (mycket kort tid + höga läxpoäng) — där koncentreras learning loss. Användare som behåller liknande tid som icke-AI får små förluster.

Mechanism

När GenAI tar över kognitivt/metakognitivt arbete syns ofta bättre uppgiftsprestation men sämre encoding — synligt först utan verktyg (closed-book).

Limits

  • Kina, ett county; GenAI-adoption identifierad via staggered timing (inte randomiserad tilldelning).
  • DP/conference paper — resultat kan revideras.
  • Kontext skiljer sig från svensk skola, men closed-book-mönstret speglar Bastani.

This claim dies if …

Replikerad K–12/HE-studie med closed-book där typisk GenAI-användning inte skadar retention relativt kontroll, och outsourcing-mönstret saknar learning loss.

Swedish implication

Nej vid typisk outsourcing — kraftig learning penalty trots “bättre” läxor. Starkaste K–12-fältbeviset hittills för ledfråga (1)/(2): mät lärande utan AI; designera bort genvägar. Svensk gymnasie-/högstadiepraktik: läxor som kan AI-lösas utan processkrav är högrisk.
