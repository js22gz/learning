Finding (+ comparator)

Comparator: skolor/kohorter före ban (event-study). Genomsnittlig nolleffekt maskerar könsskillnader. Flickor (full exponering): psykvårdskontakter ↓ (~60 % specialist intensivt); GPA +0,08 SD; lärarbetyg +0,09; externt rättad matte +0,22 SD; akademiskt gymnasiespår +4–7 pp. Mobbning ↓ båda kön. Större för låg-SES-flickor. Striktare förbud (inlämning/hotell) > endast tyst läge för betyg.

Mechanism

Minskar multitasking/FoMO-distraktion och sänker kostnad för (cyber)mobbning under skoldagen → mer encoding + bättre mående, särskilt där baseline-användning är hög (flickor/sociala medier).

Limits

Norge ≠ Sverige (jfr ATTN-006 Kessel nolleffekt); survey-svar ~40–45 % skolor; ej RCT; genomsnitt kan dölja pojkar/null.

This claim dies if …

Svensk register-DiD med samma köns-/SES-split visar nolleffekt på flickors GPA/matte och ingen mobbningsminskning efter faktisk inlämningspolicy (inte bara pappersförbud).

Swedish implication

Stop tolka Kessel (ATTN-006) som “förbud aldrig påverkar lärande”; start utvärdera SE-007-implementering med kön×SES-heterogenitet; measure faktisk separation (inlämning) vs tyst läge — fyller lucka relativt Ward/Sana med utfällda skoloutcome (nordisk).
