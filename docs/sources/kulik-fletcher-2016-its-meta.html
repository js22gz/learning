Finding (+ comparator)

Median effekt 0,66 SD vs konventionell undervisning (≈50→75 percentil). Comparator: business-as-usual / conventional classroom. Men: lokala/researcher-made test ≈0,73; standardiserade ≈0,13. Dålig implementation / icke-konventionell kontroll → små effekter.

Mechanism

ITS som anpassar uppgift/feedback till elevmodell kan lyfta achievement — men stor del av “ITS-vinsten” är test–instruction alignment, inte magisk skärmpedagogik. Implementeringskvalitet och kontrollvillkor avgör.

Limits

Inklusionskriterier kritiserade (risk för uppblåsta ES); matematik ofta mindre effekt i andra metas; pre-GenAI.

This claim dies if …

Replikerad meta med strikta standardiserade outcome och preregistrering visar median ITS-effekt ≈0 mot BAU i K–12, oberoende av alignment.

Swedish implication

Stop upphandla “AI-tutor” på vendor-ES från lokala quiz; start kräver oberoende/NP-nära mått; measure standardiserat closed-book + fidelity (jfr IFAU DIG-001/002 nolleffekt för 1:1 tillgång).
