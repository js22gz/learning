Finding

  1. WM ≠ LTM: WM = få enheter i lättillgängligt tillstånd; LTM = livstidsförråd. Encoding = att binda idéer i fokus av uppmärksamhet så de kan lagras.
  2. Kapacitet ~3–4 meningsfulla chunks hos vuxna när rehearsal/chunking begränsas; barn har lägre basic capacity (inte bara sämre filtrering eller knowledge).
  3. Utveckling: span ökar med ålder; Cowan argumenterar för genuin kapacitetsmognad utöver kunskap/strategier/hastighet.
  4. Pedagogisk huvudlinje: anpassa material till den WM eleven har (organisera, chunka, minska wait-for-theme i tal/text) — kontroversiellt hur mycket “träning” hjälper.
  5. Chunking/kunskap avlastar WM: expertis fyller slots med rikare enheter (Ericsson & Kintsch long-term WM).

Mechanism

Arbetsminnesbegränsningar styr hur mycket instruktion/elever kan hålla aktivt; träning ger oftast near-transfer, sällan far-transfer.

Limits

  • Review, inte klassrums-RCT.
  • Pågående debatt om decay vs interferens, och träningseffekter.

This claim dies if …

Preregistrerad meta där WM-träning ger robust far-transfer till skolämnen som överlever placebo och delayed test.

Swedish implication

Stop köpa WM-träning för far-transfer; start anpassa instruktion till WM-belastning.
