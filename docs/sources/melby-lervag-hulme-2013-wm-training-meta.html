Source note (Swedish, verbatim from the Kunskapsbank)

Metadata

  • ID: MEM-005
  • Tier: meta
  • N / design: meta-analys (23 studier, 30 jämförelser)
  • Population: övergripande (barn och vuxna; kliniska och typiska)
  • Subject: Is Working Memory Training Effective? A Meta-Analytic Review

Finding

  1. Near-transfer: WM-träning ger tillförlitliga kortsiktiga förbättringar på liknande WM-tester.
  2. Verbal WM: near-transfer håller ofta inte vid uppföljning; visuospatial: begränsad evidens för bestående near-transfer.
  3. Far-transfer saknas: ingen övertygande effekt på nonverbal/verbal ability, inhibition, ordavkodning eller aritmetik.
  4. Slutsats: programmen lämpar sig inte som behandling för utvecklingsrelaterade svårigheter eller som generell kognitions-/skolförbättring.
  5. Metodkritik: många studier saknar aktiva kontroller → placebo/motivation kan blåsa upp effekter.

Mechanism

WM-träning ger near-transfer till tränade tasks; far-transfer till skolämnen uteblir i meta-analyser.

Limits

  • Meta stoppar ~2011; senare studier finns — huvudslutsatsen (svag far-transfer) har i stort hållit i uppföljande reviews.
  • Blandar åldrar/kliniska grupper.

This claim dies if …

Preregistrerad meta där WM-träning ger robust far-transfer till skolämnen som överlever placebo och delayed test.

Swedish implication

Stop köpa WM-träning för far-transfer; start anpassa instruktion till WM-belastning.
