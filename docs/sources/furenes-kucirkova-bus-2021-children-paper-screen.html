Finding (+ comparator)

Comparator: samma berättelse på papper vs skärm. Enbart digitalisering → lägre story comprehension. Vuxenmediering av print > digitala enhancements när barnet läser själv. Med story-congruent enhancements kan digital slå papper. Inbäddad ordbok: −/0 för comprehension, + för vocabulary.

Mechanism

Extraneous load från hotspots/multimedia som inte förstärker storyline; germane load när enhancements är story-congruent. CLT-ram (jfr CLT-001/002).

Limits

Mest bilderböcker/berättelser (narrative) — ej sakprosa; 1–8 år generaliserar inte till åk 7–9 linjär läsning (jfr Delgado/Clinton/Salmerón).

This claim dies if …

Preregistrerad meta på 1–8 år visar null för plain digitization på comprehension och att incongruent hotspots inte skadar.

Swedish implication

Stop ersätta högläsning/print i F–3 med “samma bok i padda” utan designkrav; start print default + vuxenmediering; digital endast med story-congruent stöd; measure comprehension efter mediumbyte i förskoleklass/åk 1–3.
