Finding (+ comparator)

Assignment till Khan+Khanmigo (coach) under daily remedial math: +1,3 national percentile ranks/term (~0,06–0,08 SD/år); full aktivt år ≈0,14 SD. Comparator: skolans remedial session utan denna assignment. Effekten liknar Khan practice utan AI. 96 % provade AI; median använde det ~1/3 av practicedagar; endast 17 % av mistagssessioner hade substantiv dialog.

Mechanism

Bindande constraint = engagement, inte modellkapacitet. “Access ≠ use ≠ tutoring dialogue.” Pedagogisk konfiguration (coach) otillräcklig om elever klickar/svarar kort.

Limits

Cluster RCT; specifikt Khanmigo+Khan; ej Bastani-stil closed-book inom samma lektion; NBER WP.

This claim dies if …

K–12-RCT där coach-AI med hög substantiv dialog-rate (≥ median elev) fortfarande ger nolleffekt vs samma platform utan AI på standardiserad math.

Swedish implication

Stop räkna inlogg/licens som evidens för AI-tutor; start logga misstag→dialog-andel; measure percentile/NP + usage fidelity innan uppskalning.
