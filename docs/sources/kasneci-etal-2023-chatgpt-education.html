Finding

LLM:er “are here to stay”; AI-litteracitet + pedagogisk design + mänsklig översikt krävs; risker bias/hallucination/deskilling. Detta är position — inte effektestimat. Jämför aldrig visuellt med Bastani PNAS (AI-003, Tier RCT).

Mechanism

Normativ: utan design → cognitive offloading / skill skipping; med design → personalisering och lärarstöd.

Limits

Inte RCT/meta; tidig 2023; normativa rekommendationer. Label: ramverk, inte lärandeeffekt.

This claim dies if …

… (position falsifieras inte med en p-värde): om storskalig evidens visar att odesignad fri GenAI systematiskt höjer closed-book K–12 utan litteracitetskrav, faller paperets riskvikt — empirin avgörs av AI-003/009/metas med closed-book-flagga.

Swedish implication

Start AI-litteracitet och pedagogisk design som krav innan verktygsinförande; stop att citera Kasneci som om det vore Bastani-nivå evidens för effektstorlek.
